Features:
- Admin adds 12-13 and 13-14: private 1h bookings auto-merge into one 2h booking.
- Same student/date/instructor/spot. Reverse order supported. Only active private lessons.
- No merging booking containing historical lesson payments; no group merging.
- Instructor completion: single-student booking, actual duration 1/1.5/2 hours.
- Scheduled occupancy remains unchanged (2h remains reserved).
- 2h paid by credits, completed 1.5h: return 0.5 credit and package usage.
- 2h unpaid, completed 1.5h: price becomes 90 EUR.
- Instructor work logged at actual hours; 15 EUR/h => 22.50 EUR for 1.5h.
- Already received lesson payments are never erased; if overpaid, debt notes
  require separate Admin refund/credit handling.

IMPORTANT LIMITATIONS FOR QA:
- Group completion still uses its existing flow. Actual duration adjustment currently
  applies only to private/single-participant lessons.
- Paid adjacent lessons are deliberately not auto-merged to preserve payment histories.
- Reports derived from reserved physical slots may continue to show scheduled 2h,
  whereas instructor_hours uses actual 1.5h. Verify all report widgets before live deploy.
- SQLite unit smoke tests PASS; no Flask/browser QA yet.

Recommended QA:
